# Ailyn Diez | Portfolio

A sleek, professional, high-performance portfolio built with **HTML5**, **CSS3**, **JavaScript**, and **PHP**.

Designed in a high-contrast **Pink & Black** cyber-aesthetic with **Dark Mode** and **Light Mode**, smooth animations, **Academic Experiences**, **Featured Projects (including Video Walkthroughs)**, and **Certificates & Seminars**.

---

## 📁 Where to Put Your Files (Ready Folders)

This portfolio is front-end ready and uses organized local directories:

### 1. 📸 Your Profile Photo (`images/`)
- Save your picture inside the `images/` folder as `images/profile.jpg` (or `images/profile.png`).
- Or, directly edit the `src` attribute in `index.html`:
  ```html
  <img id="user-profile-img" src="images/profile.png" alt="Ailyn Diez" class="user-profile-photo">
  ```
- If no picture is present yet, a developer silhouette is rendered as a clean fallback.

### 2. 🎬 Your Projects Media & Videos (`projects/`)
- Project media files currently connected:
  - `projects/capstone-project.mp4` (Capstone system video walkthrough with Gemini API & NLP)
  - `projects/logo1-animation.mp4` (Logo animation & motion design demo video)
  - `projects/hms.png` (Hiring Management System preview)
  - `projects/ui-ux.png` (Hiring management system UI/UX design prototype)
  - `projects/movie-poster.png` (Creative movie poster design)
  - `projects/graphic-design-fries.png` (Commercial food branding art)
  - `projects/business-card.png` (Corporate stationery & business card layout)
  - `projects/logo1.png` & `projects/logo2.png` (Custom brand identity logo marks)
- Video items feature a clean **VIDEO DEMO** badge and open a high-definition HTML5 video player.
- Design projects feature full image previews and inspection modals.

### 3. 📜 Your Certificates & Seminars (`certificates/`)
- Save your certificate and seminar images inside the `certificates/` folder:
  - `certificates/c1.png`, `certificates/s1.png`, `certificates/c2.png`, `certificates/w1.jpg`, `certificates/s2.png`, `certificates/c3.png`, `certificates/s3.png`
- Clicking any certificate opens the certificate inspection modal with full details, issuing organization, and verification info.
- If a certificate image hasn't been added yet, the page automatically renders an SVG Certificate badge so the layout looks flawless right out of the box!

## 🚀 How to Open the Portfolio

- **Direct Browser View (Zero dependencies)**:
  Simply double-click **`index.html`** in your file manager to open it in Chrome, Edge, Brave, or Firefox.
- **PHP Server View**:
  Open your terminal or PowerShell and run:
  ```powershell
  cd "c:\Users\Irene\OneDrive\Documents\PORTFOLIO"
  php -S localhost:8000
  ```
  Then visit `http://localhost:8000` in your browser.
